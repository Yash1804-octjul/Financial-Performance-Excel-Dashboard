# Financial Performance & Business Insights Dashboard

## Project Overview

This project presents an interactive financial performance dashboard developed using Microsoft Excel to analyze business transactions and generate meaningful business insights.

The dashboard explores revenue, expenses, profit, product line performance, regional transactions, and payment methods.

## Dashboard
![Financial Performance Dashboard](https://github.com/user-attachments/assets/1f537c14-4730-4627-87c1-b030fed23f71)

## Dataset Overview

- Total Records: 2,000
- Total Columns: 12
- Time Period: 2022–2023

## Key Business Metrics

- Total Revenue
- Total Expenses
- Net Profit
- Profit Margin
- Transaction Count

## Dashboard Analysis

- Revenue and Expense Analysis
- Profit by Category
- Revenue by Product Line
- Transactions by Region
- Payment Method Performance
- Department-wise Expense Analysis

## Tools & Techniques

- Microsoft Excel
- PivotTables
- PivotCharts
- Data Analysis
- Data Visualization
- Financial KPI Analysis

## Key Insights

The analysis highlights differences in profitability across business categories, product lines, regions, and payment methods. It also identifies loss-making transactions that require further investigation.

## Project Objective

To transform raw transactional data into meaningful financial insights through interactive Excel reporting and visualization.
